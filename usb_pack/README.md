# Ultimate Second Brain — Grok handoff pack

এই প্যাকেজে রয়েছে:

- `preview.html` — browser-এ খোলা যায় এমন multi-screen interactive preview; dashboard, ১০টি database page, forms, filters, workflow, search ও export actions দেখুন।
- `GROK_HANDOFF_BN.md` — Grok-কে সরাসরি দেওয়ার implementation brief; Notion থেকে দেখা feature ও field list এবং acceptance requirements অন্তর্ভুক্ত।

## Preview চালানো

`preview.html` ডাবল-ক্লিক করে browser-এ খুলুন। এটি demo data browser-এর localStorage-এ রাখে, তাই browser storage মুছলে demo reset হবে। Preview-র profile/avatar, Exit to Portfolio, AI ও Notion import বাস্তব website/auth/backend integration চালায় না; সেগুলোকে production integration হিসেবে গণ্য করবেন না। Grok-কে existing authenticated user-এর name/avatar এবং Portfolio dashboard route যুক্ত করতে বলুন।

## Grok-কে কী দেবেন

আপনার ওয়েবসাইটের repository/source context-এর সাথে এই ZIP দিন। `GROK_HANDOFF_BN.md`-এর সম্পূর্ণ নির্দেশনা paste করে বলুন—“এই reference ও brief অনুসারে আমার বর্তমান project-এ feature implement করো।” এই প্যাক একা website source code নয় এবং একা deploy করা যায় না।
